# 🚀 Nannaka Uday — Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Machine Learning & AI Engineer.

## ✨ Features

- **Dark/Light Theme** — Toggle between themes with smooth transitions
- **Animated UI** — Scroll-triggered reveal animations, typing effect, counter animations
- **Custom Cursor** — Interactive cursor follower with hover effects
- **Fully Responsive** — Looks great on all devices (mobile, tablet, desktop)
- **Loading Screen** — Polished loading animation
- **Interactive Code Window** — 3D tilt effect showcasing code
- **Contact Form** — Ready-to-integrate contact form
- **Particle Effects** — Floating particles in the hero section

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — No dependencies, pure JS
- **Google Fonts** — Inter & JetBrains Mono

## 📁 Project Structure

```
portfolio/
├── index.html      # Main HTML file
├── style.css       # All styles with theme variables
├── script.js       # Animations, interactions, and effects
└── README.md       # This file
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/UDAYNANNAKA/portfolio.git
   ```

Human Activity Recognition (HAR) from IMU Sensors

Developed a supervised multi-class classification pipeline operating over multi-axis accelerometer and gyroscope time-series streams. Implemented signal filtering, window-based segmentation, and statistical feature extraction to accurately recognize real-time physical activities.

Input Sensors Tri-axial Accelerometer ($a_x, a_y, a_z$) + Tri-axial Gyroscope ($\omega_x, \omega_y, \omega_z$)
Signal Processing Butterworth low-pass filtering (gravitational separation) + median filtering
Window Segmentation 2.56-second sliding window with 50% overlap (128 samples per window)
Feature Engineering Time domain (mean, std, IQR, correlation) + Frequency domain (FFT energy, spectral entropy)
Applications Elderly fall detection, post-op rehabilitation tracking, smart wearable telemetry
